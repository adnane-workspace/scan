# Stratégie SEO & GEO — Scanosh

> **Objectif :** positionner Scanosh comme une solution SaaS de référence pour les menus digitaux par QR code destinée aux cafés, restaurants et snacks, avec un dashboard de gestion.

**Site de référence :** https://www.scanosh.com/

---

## 1. Positionnement SEO

### Proposition de valeur

**Scanosh = menu digital + QR code + dashboard de gestion.**

Le produit ne doit pas être positionné uniquement comme un « générateur de QR code », mais comme une solution complète de digitalisation du menu :

```text
QR Code
   ↓
Menu digital
   ↓
Expérience client
   ↓
Dashboard
   ↓
Gestion des plats, catégories, photos et prix
```

### Univers sémantiques principaux

| Univers | Mots-clés / entités |
|---|---|
| Produit | menu digital, menu numérique, carte digitale |
| QR | menu QR code, QR code restaurant, QR menu |
| Restaurant | menu restaurant, carte restaurant digitale |
| Café | menu café, carte café digitale |
| Snack | menu snack, carte snack digitale |
| SaaS | logiciel restaurant, solution restaurant |
| Gestion | dashboard restaurant, gestion menu restaurant |
| Local | menu digital Maroc, menu QR Maroc, menu digital Casablanca |
| Information | comment créer un menu QR, avantages menu digital |
| Commercial | prix menu digital, meilleur menu digital Maroc |

# 4. Héritage des pages mère / enfants

Le maillage interne doit fonctionner dans les deux sens.

```text
                MENU DIGITAL
                     │
        ┌────────────┼────────────┐
        ↓            ↓            ↓
   QR CODE       RESTAURANT      CAFÉ
        │            │             │
        ↓            ↓             ↓
     QR FAQ       Dashboard      Menu café
```

## Principe

### Page enfant → page mère

Exemple depuis `/menu-digital-cafe` :

> Découvrez également notre solution complète de **menu digital** pour les établissements de restauration.

→ lien vers `/menu-digital`

### Page mère → page enfant

Depuis `/menu-digital` :

> Découvrez comment créer un **menu digital pour café** avec Scanosh.

→ lien vers `/menu-digital-cafe`

### Résultat recherché

```text
Page mère
   ↕
Page enfant
   ↕
Article
   ↕
Autre page enfant
```

Les pages doivent former un réseau thématique cohérent.

# 6. Stratégie GEO — Generative Engine Optimization

Le GEO vise à rendre les contenus faciles à comprendre, citer et utiliser par les moteurs de recherche et systèmes génératifs.

## Principe « Answer First »

Chaque page importante doit répondre rapidement à la question principale.

### Mauvaise approche

Commencer avec plusieurs paragraphes génériques sur la transformation digitale.

### Bonne approche

Commencer par une réponse claire :

> **Un menu digital est une version numérique de la carte d'un restaurant accessible depuis un smartphone, généralement grâce à un QR code. Avec Scanosh, le restaurant peut modifier ses plats, prix et catégories depuis un tableau de bord sans réimprimer son menu.**

Puis développer.

```text

   ↓
```

```text
   ↓
blog
   ↓
pages locales
   ↓
pages restaurants
   ↓
```

- vides ;

# 15. SEO technique

## À mettre en place

- HTTPS
- URLs propres
- sitemap.xml
- robots.txt
- canonical
- meta title
- meta description
- Open Graph
- balises H1/H2/H3 cohérentes
- images optimisées
- `alt` descriptifs
- Core Web Vitals
- responsive/mobile-first
- breadcrumbs
- données structurées
- Google Search Console
- Google Analytics

## Canonical

Chaque page indexable doit avoir une URL canonique cohérente.

Éviter de rendre le même contenu accessible sous plusieurs URLs sans stratégie claire. Google indique que les contenus très similaires accessibles via plusieurs URLs peuvent être regroupés et qu'un URL canonique est choisi comme représentation principale.

---

# 16. Sitemap et indexation

Le sitemap doit contenir les URLs importantes et indexables.

Exemple :

```text
https://scanosh.com/sitemap.xml
```

Après publication :

1. vérifier le sitemap ;
2. l'envoyer dans Google Search Console ;
3. surveiller l'indexation ;
4. inspecter les pages importantes ;
5. corriger les erreurs ;
6. surveiller les performances.

**Important :** l'API Google Indexing n'est pas une API générale pour faire indexer toutes les pages d'un SaaS. Google indique actuellement qu'elle est destinée notamment aux pages `JobPosting` et `BroadcastEvent`. Pour Scanosh, le sitemap et le crawl normal sont les mécanismes appropriés pour les pages classiques.
